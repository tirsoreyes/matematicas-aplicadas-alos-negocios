moratorios, renegociación, pronto pago y comisiones.

> **Criterio docente:** no buscar profundidad matemática. Estos temas
> son herramientas para resolver problemas de negocios. Si un concepto
> matemático no ayuda a resolver un problema financiero, no dedicarle
> tiempo excesivo.

# 5. Fundamentos matemáticos

## 5.1 Exponentes

Un exponente indica cuántas veces se multiplica una cantidad por sí
misma.

Ejemplo:

`2^3 = 2 × 2 × 2 = 8`

En matemáticas financieras los exponentes serán importantes
principalmente porque aparecerán en el interés compuesto.

Por ahora explicar solamente:

-   `a^1 = a`
-   `a^0 = 1`
-   `a^2 = a × a`
-   `a^3 = a × a × a`

### Ejemplo empresarial

Una cantidad de \$1,000 elevada a una potencia no significa que el
dinero "se multiplique mágicamente"; es una operación matemática que
posteriormente se utilizará para representar periodos de capitalización.

------------------------------------------------------------------------

# 6. Logaritmos

Explicación sencilla:

Un logaritmo responde a la pregunta:

> "¿A qué exponente debo elevar una base para obtener determinado
> resultado?"

Ejemplo:

`2^3 = 8`

Por lo tanto:

`log₂(8) = 3`

No profundizar en propiedades avanzadas.

### ¿Por qué aparecen en negocios?

Principalmente cuando necesitamos encontrar un tiempo o periodo a partir
de una fórmula donde la incógnita está en un exponente.

**Nota docente:** en esta clase basta con que el estudiante comprenda
qué es un logaritmo y para qué puede servir. No dedicar más de 10--15
minutos.

------------------------------------------------------------------------

# 7. Progresiones aritméticas

Una progresión aritmética es una sucesión donde cada término aumenta o
disminuye siempre en la misma cantidad.

Ejemplo:

`100, 150, 200, 250, 300`

La diferencia es 50.

Fórmula del término n:

`a_n = a_1 + (n - 1)d`

Donde:

-   `a_n` = término que queremos encontrar
-   `a_1` = primer término
-   `n` = posición
-   `d` = diferencia común

### Ejemplo

Una empresa aumenta su presupuesto mensual en \$500:

\$5,000, \$5,500, \$6,000, \$6,500...

¿Cuánto será el presupuesto del sexto mes?

`a_6 = 5,000 + (6 - 1)(500)`

`a_6 = 7,500`

# 8. Interés simple

## 8.1 Conceptos fundamentales

Presentar estas cuatro palabras en el pizarrón:

-   Capital
-   Interés
-   Tasa
-   Tiempo

### Capital (C)

Es la cantidad de dinero inicial.

Ejemplo: se depositan \$10,000.

`C = $10,000`

### Interés (I)

Es el dinero que se gana o se paga por utilizar el capital.

### Tasa de interés (i)

Es el porcentaje que se aplica al capital durante un periodo
determinado.

Ejemplo:

`i = 8% anual`

En cálculos:

`8% = 0.08`

### Tiempo (t)

Es el periodo durante el cual se aplica la tasa.

Puede expresarse en:

-   años
-   meses
-   días

**Regla fundamental:** la unidad del tiempo debe coincidir con la unidad
de la tasa.

------------------------------------------------------------------------

# 9. Fórmula del interés simple

`I = C × i × t`

Donde:

-   `I` = interés
-   `C` = capital
-   `i` = tasa expresada como decimal
-   `t` = tiempo

## Ejemplo 1

Se depositan \$10,000 al 8% anual durante 2 años.

`C = 10,000`

`i = 0.08`

`t = 2`

`I = 10,000 × 0.08 × 2`

`I = 1,600`

El interés generado es **\$1,600**.

------------------------------------------------------------------------

# 10. Monto

El monto es la cantidad final después de sumar el interés al capital.

`M = C + I`

También:

`M = C(1 + it)`

## Ejemplo

Capital: \$10,000\
Interés: \$1,600

`M = 10,000 + 1,600`

`M = 11,600`

------------------------------------------------------------------------

# 11. Valor presente o valor actual

Si conocemos cuánto dinero tendremos al final y queremos saber cuánto
debemos invertir hoy:

`C = M / (1 + it)`

## Ejemplo

Queremos disponer de \$11,600 dentro de 2 años con una tasa simple del
8%.

`C = 11,600 / (1 + 0.08 × 2)`

`C = 10,000`

Interpretación:

> Hoy necesitamos \$10,000 para alcanzar \$11,600 bajo esas condiciones.

------------------------------------------------------------------------

# 12. Despejar la tasa

De:

`I = Cit`

despejamos:

`i = I / (Ct)`

## Ejemplo

Una inversión de \$20,000 genera \$2,400 de interés durante 2 años.

`i = 2,400 / (20,000 × 2)`

`i = 0.06`

`i = 6% anual`

------------------------------------------------------------------------

# 13. Despejar el tiempo

`t = I / (Ci)`

Ejemplo:

Capital = \$10,000\
Interés = \$1,500\
Tasa = 10%

`t = 1,500 / (10,000 × 0.10)`

`t = 1.5 años`

------------------------------------------------------------------------

# 14. Descuento

Explicar que un descuento financiero representa una reducción respecto
de un valor futuro o nominal.

## Descuento comercial o bancario

Fórmula básica:

`D = Ndt`

Donde:

-   `D` = descuento
-   `N` = valor nominal
-   `d` = tasa de descuento
-   `t` = tiempo

El valor líquido o efectivo:

`L = N - D`

### Ejemplo

Un documento tiene valor nominal de \$20,000 y se descuenta al 6% anual
durante 90 días.

Si se trabaja con año comercial de 360 días:

`t = 90/360 = 0.25`

`D = 20,000 × 0.06 × 0.25`

`D = 300`

`L = 20,000 - 300`

`L = 19,700`

**Nota:** explicar siempre qué base de días utiliza el ejercicio. No
introducir convenciones adicionales salvo que el problema las requiera.

------------------------------------------------------------------------

# 15. Descuentos por pronto pago y comisiones

## Ejemplo

Una empresa debe pagar \$50,000. El proveedor ofrece 3% de descuento por
pronto pago.

Descuento:

`50,000 × 0.03 = 1,500`

Pago:

`50,000 - 1,500 = 48,500`

Si además existe una comisión de \$500:

`48,500 + 500 = 49,000`

### Pregunta para el grupo

¿El descuento y la comisión tienen el mismo efecto?

No.

-   El descuento reduce el importe.
-   La comisión incrementa el costo de la operación.

# 16. Actividad práctica en clase

Formar parejas.

Cada pareja resolverá:

### Problema A

Una empresa deposita \$25,000 al 7% simple anual durante 3 años.

Calcular:

1.  Interés.
2.  Monto.

### Problema B

Una empresa necesita reunir \$35,000 dentro de 2 años. La tasa simple es
9% anual.

Calcular cuánto debe invertir hoy.

### Problema C

Un préstamo de \$40,000 genera \$4,800 de interés en 2 años.

Calcular la tasa anual.

### Problema D

Un documento de \$60,000 se descuenta al 8% anual durante 90 días,
usando año comercial de 360 días.

Calcular:

1.  Descuento.
2.  Valor líquido.

------------------------------------------------------------------------

# 17. Respuestas del profesor

### A

`I = 25,000 × 0.07 × 3 = 5,250`

`M = 30,250`

### B

`C = 35,000 / (1 + 0.09 × 2)`

`C = 29,661.02` aproximadamente.

### C

`i = 4,800 / (40,000 × 2)`

`i = 0.06 = 6%`

### D

`t = 90/360 = 0.25`

`D = 60,000 × 0.08 × 0.25 = 1,200`

`L = 60,000 - 1,200 = 58,800`
